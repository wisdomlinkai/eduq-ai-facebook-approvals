# Facebook Approvals Dashboard

Standalone React app for approving Facebook posts generated by n8n workflows.

## Architecture

```
fb.eduq-ai.com
       ↓
Route53 CNAME: dtwf3i8kjuxw.cloudfront.net (Amplify CloudFront)
       ↓
Amplify App: d1rdv449k3pucy
       ↓
Repository: github.com/wisdomlinkai/eduq-ai-facebook-approvals
       ↓
Branch: master
```

## Development

```bash
npm install
npm run dev  # Runs on port 3002
```

## Deployment

Push to `master` branch - Amplify auto-deploys.

```bash
git add -A
git commit -m "your changes"
git push origin master
```
